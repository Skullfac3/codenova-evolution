# 🚀 CodeNova Evolution

> **Aprende a programar. Construye tu mundo. Evoluciona hacia el futuro.**

CodeNova Evolution es una plataforma educativa que convierte el aprendizaje de programación en una aventura Pixel Art de 16 bits. Empiezas en la Prehistoria con un robot rudimentario, **Proto-0**, y cada concepto que dominas hace evolucionar tu civilización hasta la era futurista.

**Estado:** 🧪 MVP educativo (Eras 1 y 2 jugables) · **Modelo:** gratuito · **Pruébalo:** [skullfac3.github.io/codenova-evolution](https://skullfac3.github.io/codenova-evolution/)

## 🌍 ¿Qué es CodeNova?

| | |
|---|---|
| **Categoría** | EdTech · Gamificación |
| **Plataforma** | Web primero (PWA), móvil después |
| **Público** | Cualquier edad, sin experiencia previa |
| **Qué se aprende** | Programación y desarrollo web: JavaScript → web → herramientas → React/TypeScript → Next.js, Node.js y Python |
| **Lecciones** | Microlecciones de 5, 10 o 15 minutos |
| **Estilo visual** | Pixel Art 2D de 16 bits, original |
| **Progreso** | XP, niveles, NovaCoins y eras |

**Pensado para:** niñas, niños y adolescentes que descubren la tecnología; estudiantes; adultos que cambian de profesión; aspirantes a desarrollador web Junior; y cualquiera que quiera construir proyectos propios.

> **Filosofía:** no solo aprender a programar, sino **construir algo con cada conocimiento adquirido**.

## 🧭 Principios innegociables

1. **El conocimiento nunca se compra.** Ningún pago desbloquea lecciones ni ventajas educativas. La evolución es consecuencia del aprendizaje.
2. **Todo es original.** Personajes, sprites, música y textos propios.
3. **Código real, ejecutado de forma segura.** El laboratorio corre en un entorno aislado y con límites.
4. **Protección de menores primero.** Datos mínimos, sin publicidad invasiva, sin compras para menores.

## 🏺 Las cinco eras (ruta de aprendizaje)

Las **eras** son la ruta oficial: cada una corresponde a un **nivel** de contenido. No existen dos rutas distintas; *Era N = Nivel N*.

| Era | Nivel | Mundo | Qué aprendes | Estado |
|---|---|---|---|---|
| 🪨 **1. Prehistoria** | Fundamentos I | Fogatas, rocas, primer refugio | Qué es programar, instrucciones, consola, variables, constantes, tipos de datos, operadores | ✅ 7 lecciones |
| 🏛️ **2. Civilizaciones antiguas** | Fundamentos II | Arquitectura antigua, herramientas | Condicionales, ciclos, funciones, arreglos, objetos, resolución de problemas | ✅ 8 lecciones |
| ⚙️ **3. Era industrial** | JavaScript intermedio + Web | Fábricas, máquinas | Métodos de arreglos, scope, funciones flecha, HTML, CSS, DOM, eventos, formularios, JSON, APIs, promesas, async/await | 🗺️ Planeada |
| 💻 **4. Era digital** | Herramientas profesionales + React | Computadoras, redes, centros de datos | Terminal, Git, GitHub, depuración, Postman, buenas prácticas, React, TypeScript | 🗺️ Planeada |
| 🚀 **5. Era futurista** | Full stack y más allá | Ciudades futuristas, IA | Next.js, Node.js, bases de datos, backend, Python, integración con IA, arquitectura de aplicaciones | 🗺️ Planeada |

> Las eras 3 a 5 son visión de producto, no funcionalidades terminadas. La ruta se revisará conforme evolucionen las herramientas del desarrollo web.

## 🤖 Personajes

**El explorador.** Avatar personalizable que representa al estudiante: se mueve por los escenarios, interactúa con objetos, cambia de atuendo y evoluciona visualmente.

**Proto-0, el robot mentor.** Comienza como una máquina rudimentaria. Con cada era desbloquea piezas, expresiones y animaciones, y sus pistas se vuelven más avanzadas. Es un mentor, no un adorno: es quien explica errores y guía los retos.

## 🏡 Mundo, construcción y economía

**Construcción (vista superior).** Cada estudiante decora su espacio con refugios, árboles, flores, caminos, fogatas, animales y objetos desbloqueables.

**Persistencia por era.** Al avanzar a una nueva civilización se guardan el escenario, la decoración, el inventario y el progreso de la anterior; se crea un mundo nuevo y el estudiante puede llevarse **una mascota** de la era previa. Las civilizaciones anteriores siempre se pueden visitar.

**NovaCoins.** Se ganan completando lecciones, retos, evaluaciones y retos diarios. Se gastan solo en cosméticos: decoraciones, atuendos, mascotas y accesorios.

**Vista lateral (planeada).** Misiones especiales tipo plataformas para desafíos y aventuras educativas.

## 📚 Sistema educativo

Cada microlección (5, 10 o 15 min) sigue siempre la misma estructura:

1. Introducción sencilla → 2. Concepto → 3. Ejemplo → 4. Ejercicio interactivo → 5. Retroalimentación de Proto-0 → 6. Recompensa → 7. Siguiente desafío

La duración elegida cambia **la cantidad de práctica**, no el concepto: la versión de 5 min tiene el ejercicio principal y las de 10 y 15 min añaden retos extra.

**Evaluaciones:** al final de cada módulo, máximo 5 preguntas más ejercicio práctico, con retroalimentación y recomendaciones. Se inspiran en lo que se espera de un desarrollador Junior, sin prometer empleo.

**Proyectos de fin de semana:** calculadora, lista de tareas, generador de contraseñas, app del clima, gestor de gastos, catálogo, página personal y dashboard, listos para publicar en GitHub Pages y en un portafolio.

El contenido de las lecciones vive en [`src/learning/lessons/`](src/learning/lessons/).

## 🧪 Laboratorio de código

Editor con resaltado de sintaxis, números de línea, consola, validación automática, errores explicados en lenguaje sencillo y pistas de Proto-0.

```js
const nombre = "Explorador";
console.log("Hola, " + nombre); // → Hola, Explorador
```

**Seguridad:** el código del estudiante se ejecuta en un `<iframe sandbox>` servido desde **otro origen**, sin acceso a la sesión, al almacenamiento ni al DOM de la app, con límite de tiempo y de salida. Un Web Worker por sí solo no es una barrera de seguridad suficiente. Detalles en [`docs/MIGRACION.md`](docs/MIGRACION.md#5-laboratorio-sandbox-seguro).

## 🛠️ Arquitectura técnica

| Capa | Tecnología |
|---|---|
| Interfaz | React + TypeScript |
| Compilación | Vite |
| Juego | Canvas 2D (motor propio ligero) |
| Editor | CodeMirror 6 |
| Backend y cuentas | Supabase (Auth + PostgreSQL + RLS) |
| Offline | PWA (Service Worker + IndexedDB) |
| Pruebas | Vitest + Playwright |
| Publicación | GitHub Pages vía GitHub Actions |

> **Nota:** la aplicación se construye con **Vite**. Next.js aparece en el proyecto como **tema de estudio** de la Era 5, no como framework de la app.

```
codenova-evolution/
├── public/               # sprites, audio, mundos
├── src/
│   ├── components/       # Explorer, Robot, Navigation, Interface
│   ├── game/             # engine, movement, animations, worlds, inventory
│   ├── learning/         # lessons, challenges, evaluations, roadmap
│   ├── editor/           # editor y sandbox
│   ├── services/         # auth, database, sync, storage
│   ├── hooks/ · types/ · utils/
│   └── App.tsx
├── supabase/migrations/  # esquema de base de datos
└── docs/                 # documentación técnica
```

La base de datos, las políticas de seguridad y las funciones de recompensa están en [`supabase/migrations/0001_init.sql`](supabase/migrations/0001_init.sql).

## ▶️ Cómo ejecutar el proyecto

Requisitos: Node.js 20+ y npm.

```bash
git clone https://github.com/<tu-usuario>/codenova-evolution.git
cd codenova-evolution
npm install
npm run dev        # servidor local en http://localhost:5173
npm run test       # pruebas unitarias
npm run build      # versión de producción en dist/
```

Para conectar Supabase, copia `.env.example` a `.env.local` y completa:

```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

> El prototipo HTML original se conservará en `legacy/` mientras se migra el mundo del juego.

**Pruebas:**

```bash
npm test           # 99 pruebas: lecciones, validador y guardado
npm run test:e2e   # recorrido completo de las Eras 1 y 2 en móvil y escritorio
```

## 🔐 Privacidad y menores

- Datos mínimos: nombre de explorador y avatar. Sin fecha de nacimiento completa: solo un rango de edad.
- Cuentas protegidas con Supabase Auth; nunca se guardan contraseñas en texto plano.
- Cada usuario solo puede leer y modificar su propia partida (Row Level Security).
- Recompensas validadas en el servidor; el cliente no puede asignarse XP ni monedas.
- Sin publicidad invasiva ni compras para menores.
- Antes del lanzamiento: política de privacidad, términos de uso y revisión legal por país (p. ej. COPPA, RGPD y la normativa mexicana de protección de datos).
